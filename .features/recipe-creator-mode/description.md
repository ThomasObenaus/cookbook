The user should have a separate mode for creating a recipe. the user should be able to access the mode from the main menu or a dedicated button within the application.

# First Increment

- The user can enter the recipe creator mode.
- The user can input the recipe title.
- The user can input the list of ingredients.
- The user can input the preparation steps.
- there should be a main image for the recipe, the user can select an image from the gallery.
- The user can save the recipe and return to the main menu.
- cooking and preparation times are set to dummy values initially, the user can't set them until later increments.

# Next Increments

- The user can take a new photo with the camera and set it as the main image for the recipe.
- The user can add additional images to the recipe.
- The user can add the steps for the recipe one by one and optionally attach an image to each step.
- the user can define a time for each step of the recipe.
- the user can define tags for the recipe.
- the user can define the difficulty level for the recipe.
- the user can define the cooking and the preparation time for the recipe.
