A recipe catalog should be the main focus, allowing users to browse, search, and view detailed recipe information.

# First Increment

The first increment will focus on implementing the core functionality of the recipe catalog, including:

- Browsing recipes
- Searching for recipes by name only
- Viewing detailed recipe information like ingredients, and instructions
- Dummy recipe data for the first increment, placeholder pictures
- local persistence for storing recipe data only

# Next Steps

After the first increment, the next steps will include:

- Enhancing the search functionality to include ingredients and tags
- Adding the ability to sort and filter recipes
- Pin favorite recipes
- shared persistence for storing recipe data across devices
