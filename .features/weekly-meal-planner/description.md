The user should have next to the recipe cataloge view a view where a weekly meal planner can be managed.

# First Increment

- The user should see a weekly meal planner view next to the recipe catalog view.
- in thie view he should see per default the current week
- the user should be able to change the week being viewed.
- the week-view should show 7 days with name and date
- each day should have 3 slots for meals (breakfast, lunch, dinner)
- when tapping on a slot the user should be able to select a recipe for that meal from the recipe catalog.
- if the slot already has a recipe assigned, the user should be able to change or remove it.
